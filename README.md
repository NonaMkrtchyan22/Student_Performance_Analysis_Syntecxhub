# Student Performance Analytics Dashboard

## Project Overview
This project is part of the Data Analyst Virtual Internship program (Task 1). It focuses on identifying key drivers of academic success and failure using a comprehensive dataset of 2,392 student records. A dynamic dashboard was engineered in Microsoft Power BI to deliver actionable insights for educational administrators.

## Key Insights (Findings)
* **High Failure Rate:** Over 50.6% of the student population is classified under Grade Class F. Combined with Grade Class D (17.31%), nearly 68% of students are underperforming.
* **Absence Impact:** The data reveals a strict inverse correlation between absenteeism and GPA. Chronic absences (20-30 days) aggressively degrade the average GPA toward 1.0.
* **Parental Support:** Students with "Very High" and "High" parental involvement consistently maintain significantly superior GPAs compared to those with low or no support.
* **Tutoring Advantage:** Students who receive additional tutoring achieve a noticeably higher average GPA than those who do not.
* **Demographic Baseline:** Academic performance remains uniform across all ethnic groups (~1.9 GPA), showing that the issue is systemic across the entire institution.

## Strategic Recommendations
1. **Early Warning System:** Implement an automated administrative alert when a student crosses 5 unexcused absences to trigger counselor intervention.
2. **School-Funded Tutoring:** Launch peer-to-peer study networks focusing on Grade Class F and D cohorts to lift the institutional GPA baseline.
3. **Parental Engagement:** Create interactive digital progress portals and workshops to guide families on supporting students at home.
